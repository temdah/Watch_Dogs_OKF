# Watch Dogs OKF

A shared knowledge base for modders working on **Watch Dogs**: engine internals,
file formats, native interfaces, experiments, failed approaches and known limits.
Most research concerns Watch Dogs 1; successor-engine comparisons are labelled.

- [Start here](index.md)
- [Browse by subject](topics/index.md)
- [Engine fundamentals](projects/shadow-engine/research/engine-fundamentals.md)
- [Function maps](projects/index.md)
- [Evidence availability and limitations](evidence/index.md)

Findings distinguish static analysis, offline checks and human runtime results.
Addresses belong to specific executable builds. Undistributed evidence is identified
by stable IDs and hashes; those references do not make the raw material public.

Mod implementation remains in its own repository, including
[Shadow Engine](https://github.com/temdah/Shadow-Engine). This repository contains
documentation, not game binaries, proprietary dumps or installable mods.
