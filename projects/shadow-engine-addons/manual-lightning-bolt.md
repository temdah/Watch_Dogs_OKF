# Prototype evidence boundary

The current recorder/playback source and historical visible-carrier tests establish
the prototype described below. Internal World v2.1.30 remains its packaged
baseline; neither a final appearance nor complete scene/lifetime acceptance is
established. The source preflight records hashes and the unresolved boundaries.

# Carrier and ownership

The recorded Global AddTrace boundary is RVA B59760 with 19 exact displaced bytes.
It receives manager, start/end, speed, width/stop pair, material/particle handles,
tail lifetime, an inherited scalar, owner address and render-sample byte. The
internal detour forwards native calls, captures the first eligible contract and
serves both the independently armed world marker and bolt recorder. This role is
supported by current source and historical visible carrier tests; it is not a
new runtime mapping or proof for every regional build.

Current capture increments owner+18 and uses ResourceCopy at 8B3CD0 to retain
material/particle handles. Their IDs are read at untagged handle+20. This records
what the prototype does, not a newly verified acquisition/release ABI. The copy
function lacks an independent signature gate in this module. Manager is borrowed;
the pinned ASI retains the other capture state for process lifetime. Destructor,
manager scene lifetime and safe renderer calling thread remain unproved.

Arm accepts the next matching resource-ID/width/stop contract. Transient shot owner
equality is deliberately not required: the old equality gate rejected otherwise
usable shots. Through31 a fresh process required a base shot before Arm. The
corrected flow permits Arm once the observer is installed, preserves that request
through initial resource capture, then records the same eligible shot's endpoint
in the existing hook. No second setup shot is required. A native integration test
exercises Arm with no captured carrier, one hook call and the exact recorded
endpoint; unavailable observer, busy sequence and world-marker guards remain.
The copied endpoint is a trace endpoint, not a proven hit or ground position.

# Geometry and playback baseline

Internal v2.1.30 emits 16 main segments across 100 units above the endpoint. Four
three-segment branches are generated but omitted by the emitter. Each main
segment uses captured width times 20 on the first stroke and 12 on the second,
zero particle tail, render sample 1, and speed=segment length/1.5 seconds. The
second stroke is requested after 700 ms using GetTickCount from the Lua watcher.
Those settings are prototype policy, not an accepted final appearance.

Cancel stops future emission and recording; existing native traces expire.
Shutdown also disables the session and invalidates the recorded aim, but carrier
references remain. A late tick can submit the second stroke after a long pause.
The existing native stub tests cover counts, busy rejection, repeat, cancel and
shutdown. They do not prove appearance, depth/occlusion, resource ownership or
safe scene transitions. Do not treat readability or elapsed-time freshness as
proof that a cached manager is safe to call.

Manual Play adds no light or sound. [Shared automatic storm](public-storm-runtime.md)
owns its separate accepted flashes/thunder and Moon isolation. Synchronization
and automatic spatial placement need their own explicit design. Unfinished bolt functionality remains internal; the shared menu and independent tools retain their existing ownership.

# Recorded runtime control

An installed ASI matching the packaged internal2.1.30 SHA256
968B0E50E13C2038418EF0DEB6E09DE1369FFA5DD407AB19B797BC33A298C7BF
records four begins, four first/second stroke pairs and four completions at one
recorded endpoint. Initial Arm-before-carrier and Play-before-recording requests
reject explicitly, then capture and repeat playback succeed. The supplied
animation shows short separated bright segments along the channel. This supports
visible carrier/repeat operation; exact frame-to-log synchronization is unavailable.

The single Cancel occurs after a completion and before another Play, so this run
does not establish interruption of an active stroke. No cross-scene, re-recorded
position or comprehensive depth/occlusion result is inferred. One native thunder
command returns success, which is not independent audibility evidence.
