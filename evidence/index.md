# Evidence availability

The [catalog](catalog.json) identifies evidence cited by the concepts. Public
links can be followed directly; many captured images, logs and source snapshots
are not distributed here. A digest identifies a recorded file but does not make
it publicly reproducible or independently verified.

Concepts preserve the observed result, build/profile and limits so readers can
assess the claim. Native mappings are not portable between executables. Mod source
and raw records remain with their owners; this bundle contains documentation.
